# VAR Data Specification

This file describes the active annual VAR dataset consumed by `lifecycle.var`.
It supersedes the older quarterly nominal/TIPS notes.

## Active Dataset

Output file:

```text
data/var_dataset.csv
```

Builder:

```text
python data/build_var_dataset_ar1_10y.py
```

Compatibility entry point:

```text
python data/build_var_dataset.py
```

The compatibility script delegates to the AR(1)-matched 10-year RLONG builder.

## Sample And Frequency

```text
frequency: annual, January-to-January
sample:    1920-2011
T:         92 rows
```

Rows are labelled by calendar year `t`. State variables are observed in January
`t`; return variables in row `t` are realized over `[t-1, t]`.

The VAR estimation uses row `t` states to predict row `t+1` returns.

## Columns

`data/var_dataset.csv` has exactly these columns:

```text
year, cape, spr, y_1, xr, xb
```

| Column | VAR role | Definition | Units |
|---|---|---|---|
| `cape` | state | `-log(Shiller CAPE)` | log level |
| `spr` | state | real 10-year spread, `y_10_real - y_1` | log-yield spread |
| `y_1` | state | real one-year log yield/return | annual log return |
| `xr` | return | stock log excess return | annual log excess |
| `xb` | return | 10-year real bond log excess return | annual log excess |

State indices: `[0, 1, 2] = [cape, spr, y_1]`.
Return indices: `[3, 4] = [xr, xb]`.

There is no `rtb` column in the active model. The real bill is deterministic
given the current state:

```text
log R_bill,t+1 = y_1,t
```

## Inflation Expectations

The baseline uses static full-sample AR(1) expectations from Shiller
December-over-December log CPI inflation:

```text
pi_{t+1} = a + phi * pi_t + eps_{t+1}
a        = +1.289pp
phi      = +0.3884
mu       = +2.107pp
```

January `t` states use December `t-1` inflation information. The bill subtracts
the one-year AR(1) forecast; the long yield subtracts the AR(1) average
10-year forecast.

## State Construction

```text
y_1_nom,t    = log(1 + R_t / 100)
y_10_nom,t   = log(1 + RLONG_t / 100)

y_1,t        = y_1_nom,t  - E1_t
y_10_real,t  = y_10_nom,t - E10_t
spr_t        = y_10_real,t - y_1,t
cape_t       = -log(CAPE_t)
```

## Return Construction

Stock excess return:

```text
xr_t = log((P_t + D_t) / P_{t-1}) - y_1_nom,t-1
```

Real 10-year bond return:

```text
Y_10,t = exp(y_10_real,t) - 1
D_t    = (1 - (1 + Y_10,t)^(-10)) / (1 - (1 + Y_10,t)^(-1))
r_10,t = D_{t-1} * y_10_real,t-1 - (D_{t-1} - 1) * y_10_real,t
xb_t   = r_10,t - y_1,t-1
```

Thus `y_1,t` itself is the one-period real bill return from `t` to `t+1`,
while the long-bond return is generated by the level and change in the real
10-year yield.

## VAR Estimation

`lifecycle.var` estimates a restricted, mean-pinned VAR(1):

```text
z_{t+1} - z_bar = Phi * (z_t - z_bar) + eps_{t+1}
```

Only lagged state variables are regressors. Lagged `xr` and `xb` columns in
`Phi` are exactly zero. The intercept is recovered as:

```text
const = (I - Phi) * z_bar
```

Baseline diagnostics:

```text
max |eig(Phi)| = 0.9296
R2: cape=0.7999, spr=0.3736, y_1=0.6490, xr=0.0960, xb=0.1294
Sharpe: xr=+0.367, xb=+0.129
```

The hardcoded full-system fallback in `lifecycle/var.py` is synchronized with
the current `data/var_dataset.csv`.
